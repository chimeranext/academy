# Certificaciones ISTQB — Preparación

Sección dedicada a la preparación para certificaciones **ISTQB** (ISQI). Material
sintetizado de los PDFs oficiales (exam-structure tables/rules, syllabi, sample exams)
y de transcripts de entrevistas de QA.

## Contenido

| Documento | Para qué |
|---|---|
| [`istqb-certification-prep.md`](./istqb-certification-prep.md) | Estructura de exámenes, pesos por área, distribución K1–K4, estrategia priorizada por certificación (CTFL, GenAI, CTAL-TA/TAE/TM). |
| [`qa-interview-teachings.md`](./qa-interview-teachings.md) | Enseñanzas transversales de entrevistas de QA: preguntas frecuentes, frameworks de respuesta, técnicas de diseño, herramientas. |

## Cómo usar

1. **Primero** lee `istqb-certification-prep.md` para conocer la estructura y dónde
   están los puntos de cada certificación.
2. **Luego** usa `qa-interview-teachings.md` como compañero práctico: el fluido,
   con ejemplos, esperado en una entrevista.
3. Prioriza por peso (sección de estrategia). El umbral de aprobado es siempre
   **≥ 65% de los puntos, redondeando hacia arriba**.

## Enlace

Estos materiales se originan en `better-toolkits` (assurance-toolkit) y se mantienen
aquí para capacitación. El toolkit conserva únicamente el comportamiento de los skills
(BDD/Jidoka/No-Workarounds) derivado de estos insights.
